::、require 與 Bioconductor指名道姓、安全地安裝、生資套件


  
2-1套件::函式：不 library 也能用

  
只要套件裝過，就可以用 套件名::函式名 直接指定，不必先 library。好處是一眼就看得出函式來自哪裡，而且只借用一個函式。



  
2-2同名函式：誰蓋掉誰？

  
不同套件可能有同名的函式。R 找函式時，照 search() 的順序從左找到右，新載入的套件會插在最前面，所以會「蓋掉」（mask）後面的同名函式。載入 dplyr 時 R 會主動提醒：


  
這段訊息是說：載入 dplyr 之後，直接寫 filter() 會用到 dplyr 的版本，stats 的 filter() 被蓋掉了。想用被蓋掉的那個，就寫 stats::filter()。（這個網頁版只模擬 dplyr 的安裝和載入，它的函式要到 RStudio 裡才能用。）


  
2-3library、require、requireNamespace


  

    
寫法找不到套件時適合

    
library(x)錯誤，程式停止腳本開頭：少了套件就應該立刻知道

    
require(x)警告，回傳 FALSE，程式繼續寫在函式裡；一般腳本用 library 比較好

    
requireNamespace("x", quietly = TRUE)回傳 FALSE，什麼都不印檢查有沒有裝

  

  
把它們組合起來，就是「沒裝才裝」的常見寫法。分享給同學的腳本可以這樣寫，就不會每次都重新下載：

序列被拆成好幾行，要把屬於同一個標題的行接起來。技巧是：用 cumsum() 幫每一行編號，每遇到一個標題，編號就 +1。

表格讀進 R 會變成 data.frame。它其實就是一個 list：每個元素是一欄（一個向量），而且每欄一樣長。所以 list 學過的 $、[[ ]]、lapply 全部都能用。

檔案裡寫的 NA 會自動變成 R 的遺漏值；數字欄變成 num（整數是 int），文字欄變成 chr。


  
5-2篩選列：小心 NA


  
NA > 20 的結果是 NA，用 NA 去挑列，R 不知道要不要，只好給你一列全是 NA 的資料（列名也變成 NA）。篩選前先 !is.na()，或用 which()（它會自動丟掉 NA）。


  
5-3write.csv：記得 row.names = FALSE



  
write.csv 的小規則文字和欄位名稱會加上雙引號；數字、TRUE/FALSE、NA 不加。row.names = FALSE 不寫列名。寫出去的檔案用 Excel 打開也看得懂。

07
RDS 存檔與 source原封不動存下 R 物件、重複使用自己的函式


  
CSV 很通用，但它只是文字：R 讀回來時要重新「猜」每欄的型別。有時候會猜錯——


  
病歷號、檢體編號、郵遞區號這種「長得像數字的文字」最容易出事。另一個問題是：list、巢狀的資料根本放不進一張表。


  
7-1saveRDS / readRDS：存一個物件


  
.rds 是 R 專用的二進位檔，用記事本打開是亂碼（看看 💻 硬碟裡的 run.rds）。適合存分析到一半的結果，下次直接讀回來，不用從頭再跑。


  
load() 不會告訴你它蓋掉了哪些變數，所以一般建議用 saveRDS / readRDS：讀回來的東西叫什麼名字由你決定。

  

    
格式寫 / 讀別的軟體能開？型別保留？適合

    
.csv / .tsvwrite.csv / read.csv✓ Excel、任何程式✗ 要重新猜交換表格資料

    
.txtwriteLines / readLines✓✗ 全是文字序列、紀錄、報告

    
.rdssaveRDS / readRDS✗ 只有 R✓ 完全保留存一個 R 物件（list、模型……）

    
.RDatasave / load✗ 只有 R✓一次存很多物件（小心覆蓋）

  


  
7-2source()：執行一個 .R 檔

  
常用的函式可以寫在自己的 .R 檔裡，用 source() 執行整個檔案，函式就定義好了。這和 library 很像，只是來源是你自己的檔案。

套件
install.packages("x") 一台電腦一次（要引號）；library(x) 每次開 R、寫在腳本最上面；只借一個函式用 x::f()；生資套件用 BiocManager::install()。

    
路徑
用 getwd()、list.files() 確認位置；一律寫相對路徑；用 RStudio Project 代替 setwd()；Windows 路徑改用 /。

    
讀檔
先 readLines(f, n = 5) 看原始檔，再選 read.csv / read.delim / read.table，設定 na.strings、skip、colClasses；讀完用 str() 檢查型別。

    
寫檔
先 dir.create("results", showWarnings = FALSE)；表格用 write.csv(x, f, row.names = FALSE)；R 物件用 saveRDS；永遠不要覆蓋 data/ 裡的原始檔。
