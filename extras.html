01

if / else 完整版多條路選一條、else 的位置、if 也會回傳值

遊戲裡大多只用到「條件成立就做」的 if。真正判讀資料時，常常是好幾種情況選一種，這時要用 if … else if … else。

1-1多選一：else if 鏈

🧪 情境：空腹血糖判讀≥ 126 mg/dL 為糖尿病範圍、100～125 為糖尿病前期、< 100 為正常。

R 會由上往下一個一個檢查，執行第一個成立的分支，其他分支就全部跳過。所以 glu >= 100 那一行其實隱含了「而且 glu < 126」──能走到那裡，代表上一個條件已經是 FALSE。

試試把 glu 改成 130、95 再執行。

順序很重要把範圍大的條件放前面，後面的分支永遠輪不到。下面這段把順序寫反了，glu = 130 會被判成什麼？

1-2else 一定要接在 } 的同一行

在 RStudio 的 Console 或程式最外層，R 是一行一行讀的。讀到 } 後面換行，R 就以為 if 已經結束了；下一行突然出現 else，它不知道要接在誰後面，就會出錯。執行看看：

習慣寫法永遠寫成 } else {、} else if (…) {，放在同一行。（包在迴圈或大括號裡時不會出錯，但養成同一個習慣最安全。）

02

在迴圈裡存結果先準備好容器，再用 x[i] <- 一格一格填進去

cat() 只是把東西印在螢幕上，印完就沒了。分析資料時，我們通常要把每一圈算出來的結果存起來，之後再畫圖、做統計。R 最常見的寫法是：

  1. 先用 numeric(n) 建一個長度 n、全是 0 的向量（容器）。
  2. 迴圈裡用 結果[i] <- … 把第 i 個答案放進第 i 格。
🌡️ 情境：體溫單位換算儀器輸出華氏溫度，要換成攝氏：°C = (°F − 32) × 5 / 9。

執行後看下面的變數：celsius 從 0 0 0 0 一格一格被填滿。numeric() 之外，還有 character(n)（全是 ""）和 logical(n)（全是 FALSE）。

2-1為什麼不要一直用 c() 接在後面？

在生資實戰那關，我們用 pos <- c(pos, i) 收集突變位置。這樣寫結果是對的，但每做一次，R 都要建立一個新的、長一格的向量，再把舊的內容整份複製過去。

🔗 回想「記憶體裡的 R 物件」vector 是一排連續的抽屜，長度是固定的。要多一格，只能找一塊新的空間整排搬過去。資料有 10 萬筆時，就會搬 10 萬次。
寫法什麼時候用
out <- numeric(n) ＋ out[i] <- …事先知道會有幾個結果（例如每個病人一個值）
out <- c() ＋ out <- c(out, …)不知道會有幾個（例如只收集「突變的位置」），而且資料量不大

2-2放到超出長度的位置會怎樣？

R 不會報錯，而是自動把向量拉長，中間空出來的位置補上 NA（缺失值）。這常常是 bug 的來源：容器長度和迴圈次數對不上，結果裡就會冒出 NA。

練習 2

累積檢體數

向量 counts 是每天新增的檢體數。做出向量 cum：第 i 格是「到第 i 天為止的累積數量」。例如 c(12, 0, 7, 3) → c(12, 12, 19, 22)。請用 numeric() 預先準備容器，再用 for 迴圈填值。

03

走訪「值」還是「位置」for (b in dna) 和 for (i in seq_along(dna)) 的差別

for 迴圈的 in 後面可以放任何向量，迴圈變數會依序拿到向量裡的每個值，不一定要是 1:n：

寫法迴圈變數是適合
for (b in dna)值："A"、"T"…只需要內容，例如計數、加總
for (i in seq_along(dna))位置：1、2、3…需要「第幾個」、要同時看兩個向量（像 HBB 那關比對 ref 和病人）、或要把結果存到 out[i]

3-11:length(x) 的陷阱

很多人寫 for (i in 1:length(x))。平常沒問題，但當 x 是空的：

結論要走訪位置，用 seq_along(x)；要跑 n 次，用 seq_len(n)。它們在長度為 0 時會正確地「一圈都不跑」。（大魔王那關的 seq_len(total) 就是同一個道理。）

3-2在迴圈裡改迴圈變數，沒有用

for 會在每一圈開始時，從序列裡拿下一個值重新設定 i，所以你在迴圈裡改 i 不會影響下一圈。想要「跳著走」，請改序列本身，例如 seq(1, 9, by = 2)。

練習 3

直接拿值來數 GC

向量 dna 已經準備好了。不要用位置 i，寫 for (b in dna) 讓迴圈變數直接拿到鹼基，數出 G 和 C 一共有幾個，存在 gc。

檢查時會換 4 條序列，其中一條是空的。

04

向量化：不寫迴圈也能做sum()、mean()、which()、any()、all()、x[條件]

R 的運算本來就是對整個向量做的：h > 5 會一次比較每一個元素，得到一排 TRUE / FALSE。很多「用迴圈一個一個檢查」的工作，一行就能完成，而且通常更快、更不容易寫錯。

4-1常用工具

想知道寫法h <- c(3, 8, 1, 9, 4) 的結果
有幾個符合sum(h > 5)2
符合的比例mean(h > 5)0.4
符合的是第幾個which(h > 5)2 4
符合的值h[h > 5]8 9
有沒有任何一個any(h > 8)TRUE
是不是全部都all(h > 0)TRUE
逐一分類ifelse(h > 5, "高", "低")"低" "高" "低" "高" "低"

4-2生資的例子：一行就完成

那什麼時候還是需要迴圈？
  • 每一步要用到上一步的結果，例如練習 2 的累積數量（R 其實有 cumsum()，但很多計算沒有現成函式）。
  • 每一步會改變外面的世界，例如 R 寶走一步、讀一個檔案、畫一張圖。
  • 要在中途提早停止（break）。
練習 4

血糖報表：不准用迴圈

向量 glu 是一批病人的空腹血糖。不使用 for / while / repeat，算出：

  • n_high：≥ 126 的人數
  • high_idx：這些人是第幾位
  • p_normal：< 100 的人所占比例

5-2&& 和 & 不一樣

&&、||&、|

檢驗資料常有沒測到的項目，R 用 NA 表示。任何和 NA 的計算或比較，結果通常還是 NA，因為「不知道的值」加上任何東西，還是不知道：
