Part 04 · The apply family

R 寶的 apply 工廠

寫了那麼多 for 迴圈，你會發現很多迴圈長得幾乎一樣：對每一個元素做同一件事，再把結果收起來。apply 家族就是把這個固定套路包成函式。這一章從「函式也是一種值」的原理出發，先親手做出自己的 lapply，再一路用到矩陣、分組統計和生資資料。

原理：函式也是一種值把「走訪 → 計算 → 收集」的迴圈藏起來

先看一個很典型的迴圈：把一排血糖值從 mg/dL 換成 mmol/L（除以 18）。

換一個任務（開根號、算字數、四捨五入……），你會發現 ①②③ 的骨架完全不變，唯一會變的只有「對每個元素做什麼」。如果能把「做什麼」當成參數傳進去，就可以寫一次骨架、到處使用──這就是 apply 家族的原理。

apply 家族比迴圈快嗎？不一定。apply 家族的好處是寫得短、意圖清楚、不會忘記準備容器或寫錯索引，速度和「有先準備好容器的 for 迴圈」差不多。真正快的是向量化：像範例 1-1 其實直接寫 glu / 18 就好。apply 家族適合「沒有現成向量化函式」的情況，例如每個元素是一條序列、一個 list、一個病人的資料。

sapply 與 vapplysapply 自動「簡化」，vapply 事先說好形狀


  
sapply = lapply ＋ 簡化（s 代表 simplify）。它先像 lapply 一樣收成 list，再看看每次的結果長什麼樣子，能變成向量或矩陣就自動變過去：

  

    
每次 FUN 回傳sapply 的結果例子

    
都是 1 個值向量sapply(labs, mean, na.rm = TRUE)

3-2sapply 的陷阱：形狀看資料決定

  
sapply 很方便，但結果的形狀是執行時才決定的。同一行程式，資料不同，結果可能是向量也可能是 list。最常出事的是「篩選完一筆都不剩」：

  
🧬 情境：計算每條序列的 GC 數量先寫一個處理「一條序列」的函式，再交給 sapply 處理「很多條」。


  
strsplit(s, "") 會把一條序列切成一個一個鹼基，回傳的是 list，所以要用 [[1]] 拿出第一個（也是唯一一個）結果。


  
3-3vapply：事先說好每次回傳什麼

  
vapply(X, FUN, FUN.VALUE) 多了第三個參數 FUN.VALUE：一個「樣板」，告訴 R 每次的結果應該長什麼樣子。結果不符合就立刻報錯，而且空的時候也會回傳正確型別的空向量。

  

    
FUN.VALUE意思

    
numeric(1)每次回傳 1 個數字

    
character(1)每次回傳 1 個文字

    
logical(1)每次回傳 1 個 TRUE / FALSE

    
numeric(2)每次回傳 2 個數字（結果是 2 列的矩陣）

  



  
什麼時候用哪一個？在 Console 裡隨手看結果，用 sapply 最方便。寫進函式、分析流程或要交給別人用的程式，用 vapply：資料變了也不會默默換形狀，出錯時會直接指出是第幾個元素。

apply：矩陣的列與欄apply(X, MARGIN, FUN, ...)：MARGIN = 1 每一列，2 每一欄

matrix() 預設是一欄一欄填數字的：前 4 個數字是 S1 這一欄。

和 sapply 一樣，每次回傳 k 個值時，apply 會把每次的結果排成一欄。所以用 MARGIN = 1 對 4 個基因算 range，得到的是 2 × 4，基因跑到欄的位置了。要轉回來用 t()：



  
4-2搭配匿名函式

  
FUN 收到的是一整列（或一整欄）的向量，名字是另一個方向的名稱。用匿名函式就能算任何指標：



  
有專用函式就用專用函式rowSums、colSums、rowMeans、colMeans 做的事等於 apply(x, 1 或 2, sum 或 mean)，但快很多。apply 留給沒有現成函式的計算（sd、range、自訂指標）。


  
apply 不適合 data.frame對 data.frame 用 apply，R 會先把它轉成矩陣；只要有一欄是文字，全部數字都會變成文字。data.frame 的每一欄請用 sapply(df, …) 或 lapply(df, …)（data.frame 本身就是一個 list，每一欄是一個元素）。

05
mapply 與 Map：好幾組資料並排走mapply(FUN, x, y, ...)：第 i 次拿 x[i] 和 y[i]


  
sapply 一次只走訪一個向量。如果 FUN 需要兩個以上的參數，而且每次要拿「同一個位置」的值，就用 mapply（m 代表 multivariate）。注意它的參數順序和 sapply 相反：函式在前、資料在後。


  
第 1 次：b = "A", n = 3；第 2 次：b = "T", n = 1；第 3 次：b = "G", n = 2。和 sapply 一樣，結果會自動簡化，第一個參數是文字時也會變成名字。


  
5-1直接用現成的函式

  
substr(x, start, stop) 有三個參數，每條序列要從不同位置切：把三個向量並排交給 mapply 就好。



  
5-2Map：結果一律是 list

  
Map(f, x, y) 等於 mapply(f, x, y, SIMPLIFY = FALSE)：就像 lapply 之於 sapply，不做簡化、永遠回傳 list。


  
長度要一樣mapply 會重複使用比較短的那組資料（recycling）。長度不是倍數時會出現警告，通常代表資料對不上，要回頭檢查。

06
tapply 與 split：分組計算tapply(X, INDEX, FUN)：照 INDEX 分組，每組算一次


  
「各病房的平均血糖」、「每個基因的平均 Ct 值」都是先分組、再每組計算、最後合併。這正是第 1 章的拆開 → 套用 → 合併，只是「拆開」改成照組別拆。

  

    
動畫：split → apply → combine

    
glu  <- c(92, 140, 105, 88, 131, 99)
ward <- c("ER", "ICU", "ER", "OPD", "ICU", "OPD")
tapply(glu, ward, mean)

    

    

  


  
組別會照字母排序，不是照資料出現的順序。FUN 一樣可以接額外參數，回傳好幾個值時結果會是 list：


  
🔗 之後會遇到資料放在 data.frame 時，常用 aggregate() 或 dplyr 的 group_by() |> summarise()，背後是同樣的 split → apply → combine 概念。

① 有向量化函式嗎？
x / 18、sum、ifelse、rowMeans、nchar……能直接用就直接用，最快也最短。

    
② 每個元素各自獨立？
是 → apply 家族。先寫好處理「一個」的函式，再交給 lapply / vapply 處理「全部」。

    
③ 這一步要用上一步的結果？
例如累加、模擬、R 寶走迷宮 → for / while，或 Reduce。

  

  
🔗 延伸tidyverse 的 purrr 套件有 map()、map_dbl()、map_chr()，概念和 lapply、vapply 一模一樣：map_dbl(x, f) ≈ vapply(x, f, numeric(1))。學會這一章，換到 purrr 只是換名字。
